这些是"AI 凭空生成画面"，跟宝螺"用素材拼片"是两条路，只能当素材来源。

## 两个结论

**1）A 类跟宝螺重叠度很高。** 下载、转写、TTS、字幕、ffmpeg 合成，宝螺都有；
宝螺不一样的地方是**本地桌面 + 变声 / 克隆音色 + 无 watermark 素材获取**。
要比的不是"能不能生成视频"，是"本地、可控、不联网"这几条。

**2）「模板」这条路，C 类才是正解。**
之前那版模板只能"背景 + 两个方块图 + 九宫格位置"，表达力太弱，所以你觉得没用是正常的。
Remotion / hyperframes 的做法是**用组件或 HTML 描述一整屏**（文字、图片、动画、时间轴都能写），
模板 = 一段可参数化的画面描述 —— 这才撑得起"换一套模板就换一种片"。
下一步如果还要做模板，应该走这条，而不是继续加拼图参数。
