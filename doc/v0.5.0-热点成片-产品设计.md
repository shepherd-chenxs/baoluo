## 1. 背景与定位

宝螺 v0.4.0 已具备：抖音素材下载、文案提取、语音合成、声音克隆、图文解说 / 双人对话视频生成。

v0.5.0 要解决用户"不知道做什么内容"的冷启动问题，形成一条**从热点到成片**的最小闭环：

```
热点嗅探 → AI 选题 → AI 生成分镜（文案 + 图文 prompt）
→ 用户在豆包桌面版手动生图 → 拖图回工作台 → 一键合成视频
```

核心定位：**分镜工作台**，不是一键全自动出片。中间"去豆包生图"这一步由用户手动执行，换取软件零图片 API 成本、无第三方图片账号依赖。

---

## 2. 已确认的产品决策

| # | 决策 | 说明 |
|---|------|------|
| D1 | 热点数据源接入放第一位 | 另一本地项目已有成熟实现，可平移经验；对热点榜单源做归一化抽象 |
| D2 | 配图走"AI 生成 prompt + 用户手动去豆包生图" | 不接豆包/即梦 API；成本低、无需 API Key、无计费与审核负担 |
| D3 | AI 只依赖 DeepSeek | 负责选题、写文案、写图文 prompt；软件唯一外部 AI 依赖 |
| D4 | 首版锁定 AI 生图友好的内容赛道 | 情感语录、故事口播、知识观点、盘点类；不做需要真实新闻素材的硬新闻 |
| D5 | 成片形态 = 图文视频 | 静态图 + 缩放/平移运镜 + 配音 + 字幕，复用现有 narration 合成管线；不做图生视频 |
| D6 | 生成图风格统一 | AI 为整篇分镜生成统一"风格词"，自动拼进每个镜头的 prompt 尾部 |
| D7 | 新增顶级页签「热点成片」 | 不动现有「视频生成」页（图文解说/两人对话），避免页面臃肿 |
| D8 | 分镜稿落盘保存 | 一个成片方案一个目录，图随稿存，防止用户中途关闭丢进度 |

## 3. 用户流程

### 3.1 完整闭环

1. 打开「热点成片」，刷新热点榜单（抖音/微博/知乎等来源归一化列表）。
2. 选一条热点（或手动输入自定义主题）。
3. 点「AI 出方案」，DeepSeek 返回：标题、开头钩子、画面统一风格、分镜列表（每镜一句旁白 + 一条图文 prompt）。
4. 在分镜工作台逐条查看；每张镜头卡片上点「复制 prompt」。
5. 到豆包桌面版粘贴 prompt → 生成图片 → 下载保存。
6. 回宝螺，把图拖进对应镜头槽（或点槽位选文件）。
7. 选音色（支持克隆音色）→ 点「生成视频」。
8. 原地预览 mp4，可打开输出目录。

### 3.2 分支流程

- 没有想蹭的热点 → 直接输入主题生成分镜（同一套 AI 分镜能力）。
- 某一镜不满意 → 只重新生成这一镜的 prompt，其余不动。
- 某段旁白不满意 → 直接在工作台编辑文本，不影响 prompt（文案与画面各自独立可改）。

## 5. 数据结构

新文件：`src/shared/storyboard-types.ts`（与 `dialogue-types.ts` 风格一致）。

```ts
/** 一条热点：从任何榜单源抓取后统一归一成此结构 */
export interface HotItem {
  id: string;                  // source + 榜单序号拼成，唯一
  title: string;               // 热点标题
  source: string;              // "抖音" / "微博" / "知乎" / "手动输入"
  rank: number;
  heat?: string;               // 热度文本，如 "874万"
  url?: string;
  fetchedAt: number;
}

/** 一个镜头：文案与画面一一对应 */
export interface Shot {
  id: string;                  // 本地随机 id，用于编辑、重排、定向重生成
  caption: string;             // 旁白文案 = 配音文本 = 字幕文本
  imagePrompt: string;         // 给豆包/即梦的图文 prompt，已拼好风格与约束
  imagePath: string | null;    // 用户生图后拖入的图片；null = 未放图
  motion: {
    mode: "none" | "zoom-in" | "zoom-out" | "pan-left" | "pan-right";
    amount: number;
  };
  durationHint?: number;       // AI 建议秒数，仅供参考，实际以配音时长为准
}

/** 一份成片方案 = AI 草稿 + 用户后续填图 */
export interface Storyboard {
  id: string;
  title: string;               // 发布用标题（可编辑）
  hook: string;                // 开头钩子（可编辑）
  style: string;               // 画面统一风格，AI 生成并拼进每个 prompt
  sourceHot?: HotItem;         // 来自哪条热点；手动输入时为空
  shots: Shot[];
  createdAt: number;
  updatedAt: number;
}
```

### 5.1 AI 返回的草稿结构（仅 DeepSeek 输出）

```ts
export interface AiStoryboardDraft {
  title: string;
  hook: string;
  style: string;
  shots: Array<{
    caption: string;
    imagePrompt: string;
    durationHint?: number;
  }>;
}
```

前端拿到草稿后补齐 `Shot.id / motion / imagePath`，转成 `Storyboard`。

## 6. DeepSeek 输出规范

### 6.1 请求方式

- 复用现有 DeepSeek 配置：设置 → AI 服务（`apiKey` / `baseUrl` / `model`）。
- 未配置 Key 时，点「AI 出方案」提示去设置。
- 每次生成一次完整方案；单镜重生成单独请求并保留其他镜头。

### 6.2 System Prompt 固定规则

- 只输出 JSON，不要 Markdown 代码块包裹，不要多余解释。
- 画面比例：竖屏 9:16。
- 画面里不要出现文字、字幕、水印、logo。
- 每个镜头 prompt 尾部统一拼上本篇 `style`（AI 自己生成，如"治愈系手绘插画、暖色调"）。
- prompt 用中文描述，包含：主体、场景/环境、构图/镜头语言、光线氛围、风格。
- 每段 `caption` 控制在 8~15 秒可念完的长度（约 40~90 字），口语化。
- 镜头数由目标时长决定：默认 30 秒 → 4~6 镜。
- 面向小白，避免英文 MJ 模板、避免生僻参数词。

### 6.3 容错

- 解析 JSON 失败自动重试一次；再次失败返回可读错误。
- 若某字段缺失，跳过该镜头而不是整稿作废。

## 7. 存储设计

```text
%APPDATA%/Baoluo/storyboards/<方案id>/
  draft.json      # Storyboard
  shots/000.jpg   # 用户拖入的图片（复制进入，原始文件删除不影响）
```

设计要点：

- 一个方案一个目录，图片随稿落盘 → 不依赖用户原始图路径。
- 方案列表扫描 `storyboards/` 子目录读取 `draft.json` 即可，无需数据库。
- 输出 mp4 仍走现有 `outputDir/video/`。

## 8. 工作台界面设计

### 8.1 入口

侧边栏/顶部新增页签「热点成片」，与现有「视频生成」平级。

### 8.2 页面三段式

**第一段：选题区**

- 热点榜单列表：刷新按钮 + 排名 / 标题 / 热度 / 来源。
- 点击榜单条目或输入自定义主题 → 「AI 出方案」。
- 生成中显示进度（含当前阶段：写选题 / 写文案 / 写 prompt）。

**第二段：分镜工作台（核心）**

- 顶部方案信息：标题、钩子、统一风格，均可编辑；「复制全文案」。
- 镜头卡片列表，每张卡片包含：
  - 旁白文案：textarea，可直接编辑
  - 图文 prompt：可编辑 + 「复制」按钮；复制后提示"已复制，去豆包粘贴生成"
  - 图片槽位：空槽虚线提示"把豆包生成的图拖到这里，或点击选择"；有图显示缩略图 + 替换
  - 运镜下拉（复用现有 Motion 选项，默认 AI 建议）
  - 「试听这句」：试听当前旁白
- 卡片操作：重新生成这条 prompt、上移、下移、删除。
- 顶部工具栏：重新生成整稿、新增手动镜头、保存。

**第三段：生成区**

- 音色选择（含克隆音色，复用现有体系）
- 「生成视频」按钮 → 走 narration 合成
- 合成进度（复用 ComposeProgress）
- 完成后原地 <video> 预览 + 打开输出目录

### 8.3 关键交互约束

- 没放图的镜头在合成前用红色角标提示，禁止直接合成。
- 编辑旁白不影响 prompt，反之亦然；两者都允许用户改。
- 复制按钮给即时反馈（"已复制"），降低小白困惑。

### 9.2 直接复用

- 视频合成：`compose.ts` narration 模式已支持"多图 + 每图自带文案"，把 `Storyboard.shots` 映射为 `images: [{ path: imagePath, text: caption }]`，`script` 留空（走 legacy pair 分支）。
- 音色体系：TTS 音色 + 克隆音色下拉与试听。
- 字幕/输出/运镜配置与设置页。
- 生成进度与本地预览。

### 9.3 注意点

- 确认 narration 合成里每镜时长由该镜 TTS 音频长度决定，与 `durationHint` 对齐策略在开发时验证。
- 图片统一复制进项目目录，命名 `000.jpg` / `001.jpg`；换图时覆盖同名文件并更新 `draft.json`。
