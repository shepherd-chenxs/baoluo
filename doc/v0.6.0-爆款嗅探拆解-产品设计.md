# 宝螺 v0.6.0 产品设计：爆款嗅探与拆解再创作

> 状态：MVP 开发中（代码链路已接通，待真实爆款链接自测）
> 版本：v0.6.0
> 目标用户：已经在做口播/图文视频、想持续做出爆款的新手创作者

## 0. 一句话

v0.6.0 让用户“粘贴一条爆款视频 → 自动拆解它为什么爆 → 一键换成自己的主题重写一篇”，
把别人的成功方法变成可复用的选题方法，而不是单纯蹭热点或抄内容。

## 1. 背景

v0.5.0 解决了“不知道做什么内容”：热点 + 赛道 → AI 分镜 → 手动生图 → 一键成片。

但用户紧接着会遇到下一个问题：**“我怎么知道同赛道里谁做得好、为什么好？”**

平台普遍不给外部工具稳定的博主搜索接口，所以 v0.6.0 不走“自动全网找博主”，
而是先用最稳的单条链接切入，让用户自己把看到的好视频喂给宝螺。

## 2. 核心流程

```text
粘贴爆款链接（可选填赛道）
  → 宝螺解析并转出文案（Whisper）
  → AI 拆解“为什么爆”
  → 生成拆解卡
  → 一键“同方法、换主题”重写成新分镜
  → 复用 v0.5.0 分镜工作台继续生图成片
```

## 3. v0.6.0 包含

- 单条爆款视频解析与文案提取（复用素材下载 + Whisper）
- AI 拆解输出：7 类流量主类型、前 3 秒钩子、叙事结构、埋反转/评论区话术、可复用方法论
- “拆解卡”展示：一眼看懂这条为什么爆、能拿走什么方法
- 一键生成同结构、不同主题的新分镜，进入现有分镜工作台
- 拆解记录按赛道保存，简单历史列表（打开/删除），方便攒自己的“赛道爆款库”

## 4. v0.6.0 明确不做

- 不自动搜索同赛道博主、不批量抓取作品列表
- 不做粉丝量/完播率等平台数据看板
- 不直接复制爆款文案或搬运素材（只分析结构并重写）

## 5. 技术复用

| 能力 | 来源 |
|------|------|
| 链接解析/下载 | 素材捕手 parser + downloader |
| 视频转文案 | Whisper |
| 结构与重写 | DeepSeek（沿用 AI 配置） |
| 新分镜成片 | v0.5.0 HotStory 工作台与合成管线 |
| 拆解库落盘 | 参照 storyboards 目录方案 |
