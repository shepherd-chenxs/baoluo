# 宝螺 Agent 化 · 产品形态设计

> 前面的《可行性方案》讲能不能做、《低 token 方案》讲怎么省，这篇只回答一件事：**做成什么样**。
> 结论先行：**不是豆包。宝螺应该做成"工作台"，不是"聊天助手"。**

---

## 一、为什么不能照抄豆包

豆包的形态建立在"用户不知道自己要什么，AI 帮他想"这个前提上；宝螺的前提是**用户已经知道要什么，只是不想点十几步**。前提不同，形态就不能一样。

三条硬差异：

| | 豆包类通用助手 | 宝螺 |
|---|---|---|
| 产物 | 文字，看就行 | 视频/音频文件，要塞进播放器里预览、要能拖走 |
| 参数 | 少，靠多轮对话问出来 | 多且结构化（音色/语速/字幕位置/运镜/分辨率） |
| 流程 | 一问一答 | 链式（下载 → 转录 → 写脚本 → 合成），用户要"一次做完" |

所以：**豆包靠"多轮对话"解决参数，宝螺应该靠"一张能改的表"解决参数。**

---

## 二、推荐形态：工作台 + 任务卡

一句话 → 一张可改的任务卡 → 执行。三栏工作台：

```
┌──────────┬────────────────────────────────┬──────────────┐
│  侧边栏   │  任务卡（步骤 + 参数 + 产物）      │  对话         │
│ 工作台    │  ① 解析链接      ✓ 45 秒        │  …            │
│ 项目      │  ② 下载原片      ✓ 12.4 MB      │              │
│ 素材库    │  ③ 提取文案      ✓ 213 字        │              │
│ ─────     │  ④ 写脚本        ● [预览] [重写]  │              │
│ 手动模式  │  ⑤ 音色          晓晓 / 云健      │  [输入框]     │
│ 素材捕手  │  ⑥ 合成视频      ○ 未开始         │  @对话 @变声   │
└──────────┴────────────────────────────────┴──────────────┘
```

左栏：项目 / 素材库（现在散在 storyboard store 和各类草稿里的东西，收拢到一处）。
中栏：任务卡 + 产物预览。
右栏：对话。

---

## 三、任务卡是核心，三条设计原则

**1) 执行前可改，执行中可停，执行后局部重跑**

agent 最招人烦的就是"它自己跑完了、结果不对、只能重来"。任务卡把每一步摊开：第 4 步脚本不满意就只重跑第 4 步，前面下载好的视频不用再下一次。

**2) 每一步的产物都是资产，不是中间垃圾**

下载的视频、提取的文案、写好的脚本，全部落进素材库，可以单独拿走用。
这是宝螺相对"纯助手"的**结构性优势**：通用助手做完一轮就什么都不剩了。

**3) 步骤可见 = 可信**

6 步摆在那儿，用户知道卡在哪、钱花在哪。黑箱是 agent 产品最大的信任成本。

---

## 四、三个入口

1. **工作台输入框**：一句话起步，生成任务卡。
2. **快捷命令（0 token 层）**：打一个链接默认走下载；`@对话` `@变声` `@下载` 显式指定剧本 —— 这类输入直接用规则分流，不经过模型。
3. **引用上一份产物**："把上面那个转成对话视频"。链式流程全靠这个，也是纯聊天式最难做好的一环。

---

## 五、可以借豆包的两点

- **对话历史可回溯**：一条消息 = 一次可复现的操作，翻上去能重跑。
- **引用上文**：把"上一个产物"变成一等公民，而不只是一个文件路径。

---

## 六、明确不要做的三件事

1. **不要"对话框里选功能"**（就是豆包那个 + 号菜单）。那是给"不知道要什么"的场景设计的；宝螺用户目标明确，多一层菜单只是多一次点击。
2. **不要全自动无人值守**。合成要几十秒到几分钟，TTS 失败、模型没下、图片没选都是常态 —— 必须留人工确认点，否则用户会一直在做善后。
3. **不要一上来推翻现有 UI**。现有页面是高手的"手动模式"，删了会得罪老用户，而且它们本来就是 agent 的执行层。

---

## 七、分三步落地（风险递增）

| 步骤 | 工期 | 做什么 | 用户立刻得到什么 |
|------|------|--------|------------------|
| 第 1 步 | 约 1 周 | **页内助手**：现有页面右下角加一个助手浮层，只负责改当前这张表（"把第 2 镜语速改慢一点"），UI 一行不动 | 能"跟它说话"了，且没有任何迁移成本 |
| 第 2 步 | 1~2 周 | **工作台**：新增「工作台」首页 = 任务卡 + 对话；先接三条剧本（链接→成片、主题→成片、音频→变声）；现有页面收进侧边栏「手动模式」 | 一句话把整条链跑完 |
| 第 3 步 | 1~2 周 | 工作台设为默认首页；加「配方」——把调好的一套参数（音色+字幕+运镜+主题）存成模板，下次一句话复用 | 越用越省事 |

---

## 八、顺带值得做的两件事

- **素材库**：所有流程的中间产物自动入库，解决"我上次下载的那个视频呢"。
- **配方**：参数组合存成模板。这是现有"保存模板"的升级版，也是留存点 —— 用户攒的配方越多，越不会换工具。

---

## 一句话

用户要的不是"跟软件聊天"，而是**少点十几下、还看得见它干了什么**。
任务卡同时满足这两条，这也是它比纯对话框更适合宝螺的原因。
