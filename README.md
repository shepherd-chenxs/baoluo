# 宝螺

宝螺是一个 Windows 桌面软件，帮你把素材变成成片：下载视频、提取文案、配音、克隆声音、生成对话或解说视频。

## 能做什么

- **素材下载**：粘贴抖音分享链接，下载无水印视频。
- **文案提取**：把视频或音频转成文字。
- **配音**：文字转语音，支持在线音色和本地声音克隆。
- **视频生成**：输入脚本，生成对话视频或图文解说视频。
- **AI 工作台**：说一句话，自动拆成任务步骤，逐步生成和修改作品。
- **外部调用**：提供无窗口服务，可接入班底等自动化平台。

## 快速开始

```bash
npm install
npm run dev
```

首次使用 AI 写脚本或生成分镜需要填自己的 DeepSeek API Key；仓库不包含任何密钥。

## 打包

```bash
npm run dist
```
